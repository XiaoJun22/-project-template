# {{PROJECT_NAME}} 项目工程模板

电动工具/电机控制类硬件+固件项目标准工程模板。

## 使用本模板

1. 通过 Git 平台的 "Use this template" / "Create from template" 创建新项目
2. 打开根目录 [`NEW_PROJECT_CHECKLIST.md`](./NEW_PROJECT_CHECKLIST.md)，逐项完成初始化检查
3. 完整目录说明见 [`01_docs/项目目录结构说明.md`](./01_docs/项目目录结构说明.md)

## 目录速览

```
Project_Root/
├── 00_input/          # 输入资料(客户需求、参考设计、竞品资料) —— 只读，不加工
├── 01_docs/           # 方案与规格文档 —— 我方产出，做之前/做的过程中写的
├── 02_hardware/       # 硬件设计(原理图/PCB/BOM/结构/认证)
├── 03_software/       # 固件工程(内部分层结构见下)
├── 04_report/         # 测试/评审/验证报告 —— 验证结果，做完之后测出来的
├── 05_output/         # 最终交付物(固件bin、量产资料、用户手册)
├── 06_management/     # 项目管理(计划、风险、变更记录ECN)
└── NEW_PROJECT_CHECKLIST.md   # 新项目初始化检查清单
```

## 03_software 内部分层

```
03_software/
├── 01_docs/            # 软件相关设计文档
├── 02_library/          # 第三方库/厂商HAL库(最底层，几乎不改动)
├── 03_bsp/              # 板级外设初始化(GPIO/PWM/ADC/I2C) + 中断向量入口
├── 04_drv/              # 器件驱动 + 信号调理(滤波/换算/校准)
├── 05_app/              # 应用层：main.c、状态机、控制逻辑(恒流/保护)、按键LED业务
├── 06_utils/             # 通用工具函数(CRC/环形缓冲区等，不依赖硬件)
├── 07_test/              # 单元测试/台架测试脚本
└── MDK-ARM/               # Keil工程(IDE相关，独立管理，不与源码混放)
```

**数据流方向（单向）**：`05_app → 04_drv → 03_bsp`
**中断处理**：ISR入口统一放 `03_bsp/bsp_it.c`，只做一行转发；具体处理逻辑（清标志/采集）留在各外设bsp文件的 `_isr_handler()` 里，保持极简；业务判断（如是否触发保护）放到主循环轮询，不在中断里跑。

详细分层原则、命名规范、职责边界，见 [`01_docs/项目目录结构说明.md`](./01_docs/项目目录结构说明.md)。

## 命名规范

- 多轮迭代目录（PCB打样、固件版本）统一用 `Vx.x_YYYYMMDD` 命名
- 禁止使用"最终版"、"确认版"等非规范命名
